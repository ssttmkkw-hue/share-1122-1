# 雾港棋馆

一个可以直接在浏览器里玩的**酒馆自走棋**（8 人淘汰制自动战斗）。前端是纯 HTML + JavaScript；联机服务器是一个很小的 Node.js 程序，可以免费部署到 Render。

> 玩法机制完整参照“酒馆战棋”类游戏；所有随从、英雄、法术的名称、文字与美术均为原创设计，按经典流派原型（鼠群亡语、圣盾机械、吞噬恶魔、商店元素、海盗经济、复仇亡灵、鱼人团队增益等）重新设计。

## 怎么玩

- **单人**：直接用浏览器打开 `index.html`，主菜单选“单人冒险”，可选 AI 难度（简单 / 普通 / 困难）。
- **联机**：部署到 Render 后打开服务的网址，主菜单选“快速匹配”或“创建房间”。

## 联机

| 模式 | 说明 |
| --- | --- |
| 快速匹配 | 和在线玩家自动凑桌。凑满 8 人立即开局；至少 2 人时等待 20 秒后开局，空位补 AI |
| 房间 | 房主创建房间得到 4 位房间号，朋友输入房间号或从公开房间列表加入；房主可设置 AI 难度、是否公开，随时开局 |

- 服务器权威：所有规则在服务器上运行（每个房间一个独立的 vm 沙箱，跑的就是 `js/engine.js`），客户端只发送操作、播放战斗回放，无法作弊改数值。
- 每回合有招募时限（40 秒起，每回合 +5 秒，上限 90 秒），所有真人点“结束回合”后立即开战。
- 只能看到其他玩家上一场战斗的阵容，看不到对方的手牌和酒馆。
- 断线或关闭页面后，你的座位由 AI 托管；重新打开页面会自动回到对局。

### 部署到 Render（免费）

1. 登录 [Render](https://render.com)，点 **New → Blueprint**，选择这个仓库和分支。仓库根目录的 `render.yaml` 会自动创建一个名为 `mistharbor-autochess` 的 Web Service（Node，免费套餐）。
   也可以手动建 **Web Service**：Build Command 填 `npm install`，Start Command 填 `npm start`，Health Check Path 填 `/healthz`。
2. 部署完成后打开 `https://<服务名>.onrender.com` 就能玩，页面和联机服务器在同一个网址。
3. 如果服务名不是 `mistharbor-autochess`，又想从 GitHub Pages 或本地文件连接，请修改 `js/net.js` 顶部的 `DEFAULT_SERVER`，或在游戏“设置 → 联机服务器”里填写 `wss://<服务名>.onrender.com`。

免费套餐的实例 15 分钟无人访问会休眠，之后第一次连接需要等 30–60 秒唤醒，游戏里会显示提示。

可选环境变量：`QUEUE_WAIT`（匹配等待秒数，默认 20）、`HERO_PICK_SECS`（选英雄秒数，默认 25）、`TURN_BASE`（招募基础秒数，默认 40）。

本地运行服务器：

```bash
npm install
npm start          # 打开 http://localhost:10000
```

- **招募**：点击酒馆随从购买（3 铸币），点击手牌打出；或者直接拖拽。拖动战场随从调整站位，拖回酒馆出售（+1）。
- **手机**：先点一下查看卡牌详情，再点一下执行。
- **快捷键**：`R` 刷新 · `F` 冻结 · `U` 升级 · `空格` 结束回合 · `Esc` 取消选择。

## 已实现的规则

| 系统 | 细节 |
| --- | --- |
| 对局 | 8 名玩家（你 + 7 个 AI），30 生命 + 英雄护甲；随机配对、避免连续同一对手；奇数时与最近出局者的“幽灵”对战 |
| 经济 | 第 1 回合 3 铸币，每回合 +1，上限 10；购买 3 / 出售 1 / 刷新 1 / 冻结 |
| 酒馆等级 | 1–6 级，升级费用 5/7/8/9/10，每回合自动 −1；酒馆栏位 3/4/4/5/5/6 |
| 共享卡池 | 每张随从按等级 16/15/13/11/9/7 份，所有玩家共用；出售、出局都会返还卡池 |
| 种族轮换 | 8 个种族中每局随机启用 5 个 |
| 三连 | 3 张相同随从合成金色（属性 = 2 倍基础 + 所有增益，效果翻倍）；打出金色随从获得三连奖励，发现一张高一级随从 |
| 酒馆法术 | 每次刷新酒馆附带 1 个法术槽 |
| 饰品 | 第 6 回合花铸币选 1 个次级饰品、第 9 回合选 1 个高级饰品（4 选 1，共 33 种，含按种族的护符 / 战鼓） |
| 对手预告 | 招募阶段就能在排行榜上看到本回合的“下个对手” |
| 战斗 | 随从多者先攻；从左到右轮流攻击，嘲讽优先；伤害 = 酒馆等级 + 存活随从等级之和（前期有伤害上限） |
| 关键词 | 嘲讽、圣盾、剧毒、烈毒、风怒、复生、顺劈、磁力、战吼、亡语、战斗开始时、复仇（X）、光环 |
| 特殊效果 | 战吼触发两次、亡语触发两次、吞噬、商店增益（本局永久）、战斗中获得永久增益、亡语衍生物插队攻击 |
| 英雄 | 12 名原创英雄，主动 / 被动技能各半；开局 4 选 1 |
| AI | 三档难度。简单：随机性大、升本慢、不刷新不卖牌；普通：按流派与三连权重评估、按节奏升本；困难：更强的流派专注与三连意识，并用其他玩家上一场的阵容做战斗模拟来挑选站位 |
| 体验 | 合成音效（可关闭）、可选回合计时、默认战斗速度、战斗结束英雄受击动画、自动存档（刷新页面可继续） |

## 文件结构

```
index.html        页面骨架
css/style.css     基础布局与操作控件
css/tavern.css    酒馆大厅、棋盘、响应式卡框与战斗特效
assets/           原创场景与角色 WebP 图集
js/art.js         角色和法术的图集坐标
js/combat-fx.js   可加速、跳过的攻击与粒子动画
js/data.js        种族、关键词、随从（约 100 张）、法术、英雄、饰品
js/engine.js      规则引擎：卡池、招募动作、三连、战斗模拟、回合流程、AI
js/sfx.js         设置存储与 WebAudio 合成音效
js/ui.js          界面：增量渲染、拖拽、选目标、战斗回放动画、弹窗、计时、存档
js/net.js         WebSocket 连接、断线重连、请求应答
js/online.js      主菜单、快速匹配、房间、联机回合流程
server/server.js  联机服务器（静态页面 + WebSocket + 房间 / 匹配 / 权威对局）
render.yaml       Render 部署配置
```

想加新随从，只需在 `js/data.js` 里调用 `C(id, 等级, [种族], 名称, 图标, 攻, 血, { 钩子 })`。可用钩子：
`battlecry` `deathrattle` `sot` `endTurn` `startTurn` `onPlay` `onSummon` `onBuy` `onSell` `onAttack` `onFriendlyAttack` `afterFriendlyAttack` `onDamaged` `onFriendlyDeath` `onShieldLost` `onHeroDamaged` `avenge + onAvenge` `aura`。新饰品用 `K(id, 'lesser'|'greater', 费用, 名称, 图标, 文字, { 钩子 })`。
